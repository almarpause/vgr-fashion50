# Putting the Fashion 50 into your VGR "Intelligence" page (auto-updating)

The dashboard is a file your PC makes. To show it **live and self-updating** on
your Lovable site, two things run in the cloud instead of on your computer:

1. **A data feed** — `fashion50_data.json` (index history + the 50 constituents
   with price / YTD / MoM / weight / IR link + each company's weekly series +
   the watchlist). Regenerated by `python dashboard.py`.
2. **A scheduler** — a free **GitHub Action** (`.github/workflows/refresh-index.yml`)
   runs the whole pipeline **daily** and publishes the dashboard + the JSON feed
   to **GitHub Pages**. This needs no computer of yours to be on.

```
https://<user>.github.io/<repo>/                    <- the ready-made dashboard
https://<user>.github.io/<repo>/fashion50_data.json <- the data feed (CORS-open)
```

## Step 2 — turn on Pages + let the Action run

- On GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
- **Actions** tab → run **"Refresh VGR Fashion 50"** once (`Run workflow`) to
  publish immediately; after that it runs itself every day at 06:00 UTC.
- Your dashboard is now live at `https://<user>.github.io/<repo>/` and refreshes
  daily. Change the cadence by editing the `cron:` line in the workflow.

## Step 3 — show it in the VGR Intelligence section

### Option B — native VGR styling: read the JSON and render it yourself
This looks like part of your site (your fonts/colors). Paste this component into
your Lovable project and use `<FashionIndex />` on the Intelligence page. It only
needs the JSON URL. (Uses `recharts`, which Lovable projects usually already have
— if not, ask Lovable to "add recharts".)

```tsx
// FashionIndex.tsx — VGR Fashion 50, reads the live data feed.
import { useEffect, useMemo, useState } from "react";
import { LineChart, Line, XAxis, YAxis, Tooltip, ResponsiveContainer } from "recharts";

const DATA_URL = "https://<user>.github.io/<repo>/fashion50_data.json";

type Row = {
  rank: number; ticker: string; name: string; ir_url: string;
  price: number | null; currency: string; ytd_pct: number | null;
  mom_pct: number | null; full_cap_usd_bn: number; float_pct: number;
  weight_pct: number;
};
type Feed = {
  generated_at: string; base_date: string; latest_date: string;
  latest_level: number; since_inception_pct: number; n_constituents: number;
  index: [string, number][]; constituents: Row[];
  prices: Record<string, [string, number][]>; segments: [string, number][];
};

export default function FashionIndex() {
  const [d, setD] = useState<Feed | null>(null);
  const [sel, setSel] = useState<string>("");

  useEffect(() => {
    fetch(DATA_URL).then(r => r.json()).then((f: Feed) => {
      setD(f);
      setSel(f.constituents[0]?.ticker ?? "");
    });
  }, []);

  const indexData = useMemo(
    () => d ? d.index.map(([date, v]) => ({ date, v })) : [], [d]);

  const compData = useMemo(() => {
    if (!d || !sel || !d.prices[sel]) return [];
    const s = d.prices[sel]; const base = s[0][1];
    return s.map(([date, p]) => ({ date, v: (p / base) * 1000 }));
  }, [d, sel]);

  if (!d) return <div className="p-6 text-sm opacity-60">Loading…</div>;
  const names = [...d.constituents].sort((a, b) => a.name.localeCompare(b.name));

  return (
    <section className="space-y-6">
      <header>
        <h2 className="text-2xl font-semibold tracking-tight">VGR 50 — Largest Lifestyle Companies</h2>
        <p className="text-sm opacity-60">
          Market-cap weighted · float-adjusted · USD — base {d.base_date} = 1000 ·
          updated {new Date(d.generated_at).toLocaleDateString()}
        </p>
      </header>

      <div className="grid grid-cols-2 md:grid-cols-4 gap-3">
        <Kpi label="Latest level" value={d.latest_level.toFixed(2)} />
        <Kpi label="Since inception" value={`${d.since_inception_pct >= 0 ? "+" : ""}${d.since_inception_pct}%`} />
        <Kpi label="Constituents" value={String(d.n_constituents)} />
        <Kpi label="As of" value={d.latest_date} />
      </div>

      <div className="rounded-2xl border p-4">
        <h3 className="text-sm font-medium mb-2">Index level (base 1000)</h3>
        <ResponsiveContainer width="100%" height={280}>
          <LineChart data={indexData}>
            <XAxis dataKey="date" tick={{ fontSize: 11 }} minTickGap={40} />
            <YAxis domain={["auto", "auto"]} tick={{ fontSize: 11 }} width={44} />
            <Tooltip />
            <Line type="monotone" dataKey="v" stroke="#4f46e5" dot={false} strokeWidth={2} />
          </LineChart>
        </ResponsiveContainer>
      </div>

      <div className="rounded-2xl border p-4">
        <div className="flex items-center gap-3 mb-2">
          <h3 className="text-sm font-medium">Company evolution</h3>
          <select className="border rounded-lg px-2 py-1 text-sm"
                  value={sel} onChange={e => setSel(e.target.value)}>
            {names.map(c => <option key={c.ticker} value={c.ticker}>{c.name}</option>)}
          </select>
        </div>
        <ResponsiveContainer width="100%" height={240}>
          <LineChart data={compData}>
            <XAxis dataKey="date" tick={{ fontSize: 11 }} minTickGap={40} />
            <YAxis domain={["auto", "auto"]} tick={{ fontSize: 11 }} width={44} />
            <Tooltip />
            <Line type="monotone" dataKey="v" stroke="#4f46e5" dot={false} strokeWidth={2} />
          </LineChart>
        </ResponsiveContainer>
      </div>

      <div className="rounded-2xl border p-4 overflow-x-auto">
        <h3 className="text-sm font-medium mb-3">All {d.n_constituents} constituents</h3>
        <table className="w-full text-sm">
          <thead className="text-xs uppercase opacity-60">
            <tr>
              <th className="text-left py-1">#</th><th className="text-left">Brand</th>
              <th className="text-right">Price</th><th className="text-right">YTD</th>
              <th className="text-right">MoM</th><th className="text-right">Mkt cap $bn</th>
              <th className="text-right">Float</th><th className="text-right">Weight</th>
            </tr>
          </thead>
          <tbody>
            {d.constituents.map(c => (
              <tr key={c.ticker} className="border-t">
                <td className="py-1 opacity-60">{c.rank}</td>
                <td>
                  {c.ir_url
                    ? <a href={c.ir_url} target="_blank" rel="noopener noreferrer"
                         className="text-indigo-500 hover:underline">{c.name}</a>
                    : c.name}
                  <span className="opacity-50"> · {c.ticker}</span>
                </td>
                <td className="text-right tabular-nums">{c.price?.toLocaleString() ?? "—"}</td>
                <td className={`text-right tabular-nums ${pos(c.ytd_pct)}`}>{fmt(c.ytd_pct)}</td>
                <td className={`text-right tabular-nums ${pos(c.mom_pct)}`}>{fmt(c.mom_pct)}</td>
                <td className="text-right tabular-nums">{c.full_cap_usd_bn.toFixed(1)}</td>
                <td className="text-right tabular-nums">{c.float_pct}%</td>
                <td className="text-right tabular-nums">{c.weight_pct.toFixed(2)}%</td>
              </tr>
            ))}
          </tbody>
        </table>
      </div>
    </section>
  );
}

const pos = (v: number | null) => v == null ? "" : v >= 0 ? "text-emerald-500" : "text-rose-500";
const fmt = (v: number | null) => v == null ? "—" : `${v >= 0 ? "+" : ""}${v.toFixed(1)}%`;
function Kpi({ label, value }: { label: string; value: string }) {
  return (
    <div className="rounded-2xl border p-4">
      <div className="text-xs uppercase opacity-60">{label}</div>
      <div className="text-2xl font-semibold mt-1">{value}</div>
    </div>
  );
}
```

Swap `DATA_URL` for your Pages JSON URL. That's the only edit. The component
re-fetches on load, so every daily refresh shows up automatically.

## If you'd rather NOT use GitHub / the cloud
Keep it on your PC: schedule `python dashboard.py` (Windows Task Scheduler, like
the pre-flight task) and upload `Fashion50_Dashboard.html` + `fashion50_data.json`
to wherever your site reads them. Same files — it just only refreshes while your
computer is on.
